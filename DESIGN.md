# Red White and Clix — design reference

Working onboarding design system, September 21, 2026. See `brand-style-guide.md` for evidence and rules. No website build or platform migration is authorized by this reference alone.

- Primary audience: tabletop gamers, veterans, military families, supporters and sponsors.
- Primary task: register for November 7–8, 2026 events; confirm fees via HCUnits and client.
- Existing logo: `brand/red-white-and-clix-logo.png`, 700×700, client supplied.
- Logo palette: #FF0000 red, #FFFFFF white, #0072FF blue, #000000 black.
- Proposed accessible UI: #B91C1C red buttons, #0050B3 links, #111827 body ink, #F5F7FA light surfaces.
- Existing loaded typefaces: Archivo Black and Space Grotesk. Proposed roles: Archivo Black display; Space Grotesk body/UI.
- Proposed spacing: 4, 8, 12, 16, 24, 32, 48, 64px. Content max-width 1200px; reading column 70ch; modest 8px card radius.
- Keep documentary event photography distinct from generated artwork, merchandise mockups and sponsor logos.
- Mobile: one column, useful event details before long sponsor blocks, clear 44px-or-larger action targets.
- Voice: warm, professional, motivating, inclusive; no politics.
- Proposed navigation: Events, Our Mission, Veteran Resources, Support Us, Shop, About. Confirm final scope first.
- Proposed reusable components: event card, registration action, beneficiary summary, sponsor grid, photo gallery, resource card, donation FAQ.
- Asset source, rights and dimensions: `06-Reports/site-assets-manifest.json` and `facebook-assets-manifest.json`.
- CSS namespace reserved: `rwc-`. Tokens: `website/css-tokens.css`.
