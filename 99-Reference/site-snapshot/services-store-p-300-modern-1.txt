Heroclix 300 Modern Age is the standard competitive format where players build a team of characters totaling up to 300 points using figures from the current Modern Age set pool. Players compete head-to-head, using strategy and character abilities to outmaneuver opponents and score points by KO’ing opposing figures within a set time limit.
