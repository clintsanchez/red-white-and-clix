# WordPress design snapshot

Exported from the local site through Novamira on September 22, 2026.

- `site.json`: 40 published Elementor documents, active kit settings, navigation menus, relevant Meta Box definitions and allowlisted business options.
- `assets/`: referenced local image/font files.
- `asset-map.json`: mapping from original WordPress URLs to repository assets.

This is a design/source snapshot, not a full database backup or a one-click WordPress restore. It omits users, credentials, orders, submissions, and application configuration. Header/footer bindings reference the existing `options` Meta Box settings page. See `08-Website-Planning/10-GLOBAL-OPTIONS.md` for the field mapping.
